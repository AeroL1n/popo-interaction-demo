如何在 popo 发布作品？

在 dodo 发布

  1. 使用 dodo 生成页面打开 dodo Web 端 dodo.baidu-int.com 或 如流 dodo 对话，描述你想做的内容，并让它生成 HTML，说得越具体效果越好。
  2. 发布到 popo点预览页右上角的「发布到 popo」，几秒钟后就能拿到一条专属链接，可以分享给任何人，也可私密发布，在 popo 中管理自己的灵感和作品。

在 Comate 发布

  1. 下载 Comate 生成页面前往 comate.baidu.com/zh/download#ailde 下载安装，给自己配上一位全能搭子。打开 Comate 窗口，让它帮你生成页面。
  2. 一键部署到 popo在对话里说句「发布」，或直接敲 /popo 发布，一行命令就能拿到一条专属链接，可以分享给任何人，也可私密发布，在 popo 中管理自己的灵感和作品。
